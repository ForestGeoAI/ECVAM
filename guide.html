처음 사용하는 분시스템 이용 초보자를 위한 매뉴얼

WebGIS 지도 접속부터 화면 구성, 레이어 조회, 검색, 등급 분석, 모바일 이용까지 기본 사용법을 순서대로 안내합니다.

별도의 회원가입 없이 누구나 무료로 사용 가능

공간정보 다운로드나 Open API 사용 시에만 로그인 필요

01WebGIS 지도 연결

  1. https://ecvam.neins.go.kr 홈페이지 메인화면 접속

  2. WebGIS 지도보기 클릭

02WebGIS 시스템 구성

  1. 메뉴 : 레이어, 검색, 국토환경성평가등급 분석, 지형 분석, 환경입지분석, 과거자료조회
  2. WebGIS 제공 레이어 목록
  3. 행정구역 이동

  4. 레이어 선택 보기 창 on/off

  5. 의견보내기, 지도 저장, 지도 인쇄, 화면 분할

  6. 지도 확대 및 축소

  7. 지도 전체보기, 면적 측정하기, 거리 측정하기, 도형 삭제, URL 공유

  8. 배경지도 선택

  9. 마우스 우클릭 분석

03레이어 조회 기능

  1. 선택된 레이어 개수 표시

  2. 선택 레이어 초기화

  3. 선택된 레이어를 볼 수 있는 레이어 선택 보기 창

  4. 선택 레이어 순서 조정

  5. 선택 레이어 투명도 조절

  6. 레이어 on/off 와 레이어 선택 해제

  7. 개별 레이어 메타정보 확인

  8. 지도 다운로드

  9. 선택된 레이어 정보보기 통해 다중 레이어 메타정보 확인

  10. 레이어 메타정보 엑셀 다운로드

04분할화면 보기

  1. 분할화면 보기
  2. 분할화면 좌·우측 레이어 설정
  3. 좌·우 화면서 공통적으로 활용가능한 메뉴
    • 지도 전체보기, 면적 측정, 거리측정, 도형삭제, 줌 레벨

05배경지도, 도엽도, 지적도 등 조회

  1. 통계청에서 제공하는 시도/시군구/읍면동 단위의 행정구역도 제공
  2. 국토지리정보원에서 제공하는 1:25,000 축적 및 1:5,000 축적의 도엽도 제공
  3. 브이월드에서 API로 제공하는 지적도, 토지소유정보 연계 제공
  4. 브이월드에서 API로 제공하는 5가지 배경지도 연계 제공

06통합검색, 지번검색

  1. 통합검색 : 도엽/명칭/행정구역명 등 자연어 기반 검색
  2. 지번검색 : 지역 선택 후 지번으로 검색
  3. 검색결과에서 이동 버튼 클릭하여 해당 위치로 이동

  4. 검색결과에서 분석 버튼 클릭하여 해당 위치로 분석 가능

07국토환경성 평가등급 분석

  1. 국토환경성평가등급 분석 기능으로 지적분석/SHP 파일 분석/ 그리기분석/지점분석 옵션 제공
    • 지적 분석: 분석하고자 하는 지적(주소)을 입력하여 분석
    • SHP파일 분석: 분석하고자 하는 지역의 SHP파일을 업로드하여 분석
    • 그리기 분석: 분석하고자 하는 지역의 폴리곤을 그려서 분석
    • 지점 분석: 분석하고자 하는 지역을 마우스로 클릭하여 분석

  2. 분석 지역 SHP 파일 다운로드, 분석 결과 그림으로 저장, 분석 결과 엑셀로 저장, 분석 결과 보고서 인쇄

  3. 분석 결과 지도 보기

  4. URL 복사, 지도 현위치 이동, 분석 결과 원형 그래프로 보기, 분석 결과 막대그래프로 보기

  5. 분석 지역의 등급별 면적 및 비율

  6. 평가 세부 항목별 등급 및 평가근거 상세보기

08모바일 사용자 매뉴얼

모바일 WebGIS 메인 화면 구성

  • 국토환경성평가지도-메인화면 → 국토환경성평가지도 WebGIS 지도보기 클릭
  1. 레이어 구성 : 국토환경성평가지도, 법제적 평가항목, 환경생태적 평가항목, 환경 주제도, 환경관련 참조정보, 행정구역도/지적도, 대기/물 환경
  2. 배경지도 선택 기능 : 지도, 위성, 야간, 흰색

국토환경성평가 지적분석

  • 메뉴 에서 국토환경성평가 지적분석, 경사도 지적분석, 표고 지적분석 원하는 분석 선택

  • 주소 검색하여 원하는 주소를 선택하여 담기 → 분석 실행

현 위치 지점 분석

  • 돋보기 : 주소 및 건물명 검색
  • 현 위치 지점분석 → 원하는 항목(국토환경성평가지도, 법제적 평가결과, 환경생태적 평가결과)을 선택하여 지도결과 확인
  • 상세보기 클릭하여 원하는 항목의 해당 레이어 평가등급 확인

현 위치 지적 분석

  • 돋보기 : 주소 및 건물명 검색
  • 현 위치 지적분석 → 원하는 항목(국토환경성평가지도, 법제적 평가결과, 환경생태적 평가결과)을 선택하여 지도결과 확인
  • 상세보기 클릭하여 원하는 항목의 해당 레이어 평가등급 확인

  • 대기 측정소, 물환경 측정소는 주변에 측정소가 없는 경우 확인불가

원하는 지점 분석

  • 원하는 지점 길게 눌러서 주소 확인
  • 국토환경성평가 분석, 경사도 분석, 표고 분석, 대기 측정소, 물환경 측정소, 토지이용규제정보, 도시계획 열람 중 원하는 분석 선택

  • 토지이용규제정보, 도시계획 열람은 토지이음 사이트로 연결하여 규제정보 서비스 조회

레이어 구성

  • 국토환경성평가지도

  • 법제적평가항목

  • 환경·생태적 평가항목

  • 환경 주제도

  • 환경관련 참조정보

  • 행정구역도/지적도

  • 대기/물환경

국토환경성평가지도 활용안내

국토환경성평가지도(ECVAM) 시스템의 이용 방법을 대상자별로 정리한 안내서입니다.
「환경정책기본법」 제23조 및 같은 법 시행령 제11조의2에 따라 작성·보급하는 지도를 기준으로 합니다.

  • 국토환경성평가지도 ecvam.neins.go.kr
  • 국토환경정보시스템 neins.go.kr
  • 한국환경연구원(KEI)
